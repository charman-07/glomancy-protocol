# Code of Conduct

Glomancy Protocol welcomes technical participation from people with different backgrounds and levels of experience.

## Expected behavior

Participants should:

- discuss ideas and code with respect and technical clarity;
- critique changes rather than people;
- assume good faith while still requiring evidence for technical claims;
- keep discussions relevant to the open protocol project;
- respect privacy and never post another person's credentials, private data, or proprietary material;
- disclose conflicts of interest when they are relevant to a proposal.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, deliberate disruption, doxxing, publication of secrets, or repeated bad-faith behavior is not acceptable in project spaces.

## Technical disagreements

Strong disagreement is allowed. When consensus is difficult, participants should document the competing trade-offs, compatibility impact, security impact, and evidence. The maintainer makes the final repository decision under `GOVERNANCE.md`.

## Enforcement

Potential conduct problems can be reported privately to the maintainer through the GitHub contact mechanisms associated with this repository. Reports will be reviewed in context. Responses may include a warning, moderation of project interactions, or removal from project spaces when necessary.

This code of conduct applies to repository issues, pull requests, reviews, discussions, and other project-managed spaces.
