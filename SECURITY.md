# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

Use a private GitHub security advisory when available so the maintainer can review the report before details are disclosed publicly.

## Scope

This policy covers the Glomancy Protocol package and its public schemas, examples, compatibility fixtures, and validation code. It does not grant access to or disclose the separate commercial Glomancy product.

## Secrets and sensitive data

Contributions containing credentials, API keys, access tokens, private certificates, signing material, customer data, or private infrastructure details will be rejected and removed from history when necessary.
